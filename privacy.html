개인정보처리방침 (Privacy Policy)

시행일: 2026년 10월 14일

gwang-youtube-bot(이하 "이 도구")은 케이엠파트너스 유튜브 채널 운영자가 자기 채널을 관리하려고 쓰는 개인용 도구입니다.

1. 접근하는 정보

운영자가 Google 계정으로 허용한 범위 안에서 운영자 본인의 YouTube 채널에만 접근합니다.

  • 영상 업로드, 제목, 설명, 태그, 썸네일, 공개 예약 설정 (youtube.upload, youtube)
  • 운영자 채널 이름으로 댓글 작성 (youtube.force-ssl)
  • 채널 이름, 영상의 공개 상태 확인

다른 사용자의 개인정보는 수집하지 않습니다.

2. 저장과 보관

로그인 정보(인증 토큰)는 운영자의 개인 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다. 업로드 기록(영상 ID, 예약 시각)도 운영자의 컴퓨터에만 저장됩니다.

3. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다. 광고나 분석 목적으로 쓰지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

이 도구가 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 접근 권한 철회

운영자는 언제든지 Google 계정 권한 페이지에서 이 도구의 접근 권한을 철회할 수 있으며, 컴퓨터에 저장된 토큰 파일을 지우면 모든 로그인 정보가 삭제됩니다.
